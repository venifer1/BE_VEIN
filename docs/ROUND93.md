## 용어 사용자친화화 — 쉬운말 + (원래 용어) 병기 (FE)

사용자 실사용 피드백: "어제 베인 틀어보니 용어들이 다 알아듣기 어렵다." 실제로 화면에
전문용어·영문약어가 다수 노출돼 있었다(MFE/MAE, 무효화, R:R, OI, FDV, 도미넌스, Risk Guard,
워크포워드, 과적합, 스캘핑 지표 등). 사용자가 스타일을 **"쉬운말을 앞에 두고 원래 용어를
괄호로 병기"**로 택함(정확성 유지 + 초심자 이해).

### 바뀐 것 (프론트 전용, 문자열/라벨)

- **신호 상세**: `MFE/MAE` → "최고 상승(MFE)/최대 하락(MAE)"(+설명줄), `무효화` → "실패 기준
  (무효화)"·`무효화가` → "실제 실패가", `기준선` → "기준 가격", `손익비(R:R)` →
  "기대수익÷손실 (손익비)", `Risk Guard` → "위험 차단 (Risk Guard)", `Pattern Score` →
  "패턴 점수 (Pattern Score)", `적중률` → "성공률", `표본 N` → "사례 N건".
- **신호 카드/스캐너 스트립**: "과거 적중"→"과거 성공", "표본"→"사례 N건", "적중률"→"성공률",
  "표본 부족"→"사례 적음".
- **차트**: 가격선 라벨 `무효화` → "실패선".
- **백테스트**: `워크포워드 검증` → "실전 검증 (워크포워드)"(+설명), `과적합` → "과최적화
  (과적합)", `In-Sample/Out-of-Sample` → "학습 구간/검증 구간", `Profit Factor` → "손익 배수",
  `MDD` → "최대 낙폭".
- **틱띄기(스캘핑)**: 지표 라벨 스프레드→"호가차", TPS→"초당체결", 마이크로변동→"순간변동",
  불균형→"쏠림"(+안내에 용어 병기), "스캘핑 점수"→"틱띄기 점수", "벽 상태"→"대기주문 벽",
  "호가 상위 레벨"→"호가창(매수·매도 대기)".
- **데이터/파생**: `TVL` 탭 → "예치금"(+설명), `펀비차익` → "펀딩차익", `FDV` → "총가치(FDV)",
  `펀딩비` → "펀딩비(선물 보유료)", `미결제약정`↔`OI` → "미결제약정(OI)" 통일(+파생 상세 설명줄).
- **홈**: `BTC/USDT 도미넌스` → "BTC/USDT 점유율", 김치프리미엄에 "(국내-해외 가격차)" 병기.
- **알림**: `쿨다운` → "재알림 최소 간격 (쿨다운)"·"재알림 간격"(설정·다이얼로그·설명 문구).

알림 요약·신뢰 %)은 유지. 백엔드/계약/로직 무변경.
