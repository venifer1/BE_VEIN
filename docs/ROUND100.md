## 모의투자 주문 내역 방향 한글화 (FE, 용어 후속)

자율 루프 R100. 주문 내역의 방향이 아직 영문(BUY/SELL/LONG/SHORT)이라 읽는 맥락(이력)에서
어색했다. R93/R96(모의투자 용어) 후속으로 한글화.

### 바뀐 것 (프론트 전용)

- `OrderList`에 `orderSideLabel()` 헬퍼: 현물 BUY/SELL → **매수/매도**, 선물 LONG/SHORT →
  **롱/숏**(+reduce_only "청산"). 주문 폼 버튼(BUY/SELL 토글)은 관례상 영문 유지.

### 검증

`tsc`·`next build` 통과. 표시 라벨만 변경, 로직 무변경.
