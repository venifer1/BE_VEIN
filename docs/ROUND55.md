# VEIN Round 55

Date: 2026-09-12

## UI 감사 후속 정리 (전 화면 점검 + 소규모 수정)

R54에 이어 **전 화면을 데모 유저로 훑고(430px) + 코드 전수 점검(Explore 에이전트)** 해서
"이런 류(숫자 포맷·파괴적 확인·상태 처리·모바일 오버플로)"의 이슈를 찾았다. 대부분 화면은
R31~R50 정리로 이미 깔끔했고, 실제 가치 있는 것만 골라 고쳤다. 프론트 전용.

### 고친 것

1. **모의투자 초기 잔액 입력 포맷** (`app/paper/page.tsx`) — `10000000` 원시 숫자를 **천단위
   콤마**(`10,000,000`)로 표시하고, `원` 접미사 + **한글 단위 힌트**("1,000만원", 1억 이상은
   "N억 M,MMM만원")를 붙였다. 입력은 숫자만 허용(최대 15자리), `tabular-nums`.
2. **신호 성과 strip 표본부족 경고** (`app/scanner/page.tsx`) — 표본이 20 미만이면(예: 표본 3에
   적중률 100%) **"표본 부족 · 참고만"** 앰버 배지를 붙여 소표본 적중률 오독을 막는다.
3. **파괴적 액션 확인** — 되돌리기 어려운 두 동작에 `confirm` 가드 추가:
   - 조건검색식 삭제(`condition-scanner-panel.tsx`): "...삭제할까요? 되돌릴 수 없습니다."
   - Admin 사용자 잠금(`admin/page.tsx`): "...계정을 잠글까요? 로그인이 차단됩니다."

### 점검했으나 수정 안 한 것 (근거)

- **파생 탭 "빈 회색 박스"** — 오탐이었다. 코드상 로딩/에러/빈상태(EmptyState) 모두 처리돼 있고,
  스크린샷은 데이터 로드 전 **로딩 스켈레톤(h-48)**을 잡은 것. 정상.
- **관심종목 해제 · 웹푸시 토글 확인** — 둘 다 즉시 되돌릴 수 있는(재등록/재구독) 동작이라
  확인을 넣으면 마찰만 커진다 → 의도적으로 스킵.
- **모의계정 리셋 확인**(R31 계획) — 현재 UI에 계정 리셋 버튼이 없다(우상단 아이콘은 새로고침).
  넣을 액션 자체가 없어 불필요.
- **소소한 tabular-nums/truncate**(유통량 circulating, 스캐너 심볼 등) — 낮은 심각도, 실사용
  영향 미미해 이번엔 보류(후속 후보).

### 검증

- 프론트 `typecheck`/프로덕션 `build` 통과.
- **라이브**: `/paper` 입력값 `10,000,000` + "만원" 힌트 DOM 확인. **Chrome smoke 0에러**(전 라우트
  + 감사 중 콘솔/페이지 에러 0). 백엔드/계약 무변경.
