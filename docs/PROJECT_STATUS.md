## 1. 제품 개요

- **VEIN** — 코인/주식 **매매 인텔리전스 모바일 플랫폼** (내부 알파)
- 핵심 흐름: 캔들 수집 → **패턴 탐지(ABC·고점되돌림·이말올)** → 신호 저장 → 모바일 신호함·차트·분석
- **4개 시장**: 코인(업비트/바이낸스) · 미국주식 · 코스피 · 코스닥
- **컴플라이언스**: 전 화면 "투자 참고용 · 투자권유 아님" 고지 노출. **자동매매·실거래 주문 없음.**
- 브랜드 표기: **VEIN** (코드·도메인·백엔드 패키지 `com.vein`). 기존 `Veni Invest ABC`는 레거시 데스크톱 레퍼런스 구현으로만 유지.

## 2. 기술 스택 (모노레포)

| 스택 | 기술 | 상태 |
|---|---|---|
| **backend** | Spring Boot 3.3 · Java 21 · PostgreSQL 16 · Redis 7 · Flyway | 마이그레이션 **V1~V21** 적용, 단위/골든 테스트 통과 |
| **frontend** | Next.js 14 (App Router) · TypeScript · Tailwind/shadcn · lightweight-charts | build/typecheck 통과, 라이브 smoke 0에러 |
| **app** | Flutter (Dart 3) · riverpod · go_router · dio · fl_chart | 5탭 IA 구성 (SDK 검증 대기) |
| **sidecar** | Python (yfinance · pykrx · telethon · Upbit WS) | 미국/한국 주식 · 텔레그램 · 스캘핑 실데이터 브리지 |

### 모바일 IA — 하단탭 5 + 스택
- **홈/터미널**: 시장지표(공포탐욕·도미넌스·글로벌시총) · 김치프리미엄 · 급등락(4시장) · 트렌딩 · 관심종목 · 통합검색
- **스캐너**: 패턴 신호 · 조건검색 · 틱띄기 · 백테스트
- **속보**: 텔레그램(코인니스) · Bloomberg RSS
- **데이터**: 파생지표 · 펀비차익 · TVL · 유통량 · 테마/섹터 · 강제청산 스트림
- **설정**: 알림규칙 · 알림함 · 웹 알림 · 데이터출처 · 진단
- **(추가)** 모의투자 · Admin 대시보드

## 3. 구현 완료 기능

- ✅ **인증 / 관심종목 / 알림** (쿨다운 · 앱내 알림 · 웹푸시 백그라운드 VAPID)
- ✅ **4시장 시세·캔들·차트** (MA/볼린저 오버레이) + **지표** (RSI · MA · 볼린저 · MACD)
- ✅ **패턴 신호 3종** (ABC · 고점되돌림 · 이말올) + 상태전이(탐지→완성임박→무효/만료) + 실시간 가격 WebSocket
- ✅ **Pattern Score v1** (완성도30·거래량20·추세20·변동성10·뉴스20 = 100점) + 규칙기반 Explain · Risk Guard · 표본 Confidence
- ✅ **Explain 피드백** (유용해요/아쉬워요 + 사유 · 사용자별 유용률 집계)
- ✅ **조건검색기 v1** (RSI · 거래량 · MA · MACD 조합, AND/OR · 저장식 · 스케줄 실행 · 매칭 알림 · 빈도 시뮬레이션 · 템플릿)
- ✅ **백테스트 엔진** (수수료 · 목표/손절/기간 청산 · 워크포워드 IS/OOS 과적합 경고) + 전략 저장·재실행·성과 히스토리
- ✅ **모의투자 (Paper Trading)** — 현물/선물 · LONG/SHORT · 레버리지 · 부분청산 · 신호→모의진입 연결
- ✅ **시장데이터 탭** — 파생(펀딩·OI·롱숏) · 펀비차익(Bybit) · TVL(DefiLlama) · 유통량(CoinGecko) · 테마/섹터 · **강제청산 스트림**(급증 알림)
- ✅ **속보** — Bloomberg RSS + 텔레그램(코인니스) + 감성분석 · 종목태깅 · 딥링크
- ✅ **Admin 대시보드** — 회원 승인/잠금 · 감사로그 · 알림/스캐너 운영 지표

## 7. 알려진 제약 / 함정

- ⚠️ **한글+공백 경로**(`바탕 화면\베인`)에서 `gradlew test`는 Gradle 워커 @argfile 인코딩 버그로 실패(컴파일·bootRun은 정상). 테스트는 ASCII 경로(예: `C:\vein`) 복사본에서 16/16 통과 검증.
- ⚠️ 프론트는 OneDrive의 `.next` 동기화 손상 이슈로 **프로덕션 빌드(`npm run build && npm run start`)로 운영**. 코드 변경 시 재빌드·재시작 필요.
- ⚠️ Java 필드의 숫자 앞엔 snake `_`가 안 붙음(`change1d`/`trade_value24h` 등). 신규 필드는 백엔드 실제 출력 확인 후 프론트 타입 작성.
- pykrx KRX 인덱스 구성종목 API가 자주 다운 → 코스피/코스닥 구성종목은 프리셋/캐시 폴백.
