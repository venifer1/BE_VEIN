# VEIN Round 67

Date: 2026-09-12

## 신호 상세에 리스크·리워드(R:R) (R66 후속, FE)

R66이 신호 카드에 C목표 거리를 넣었다면, R67은 상세에서 **트레이드 계획용 R:R**를 더한다. 상세
DTO엔 현재가·C목표·무효화가가 모두 있어 백엔드 변경 없이 계산 가능.

### 바뀐 것 (FE)

- 신호 상세 "무효화 기준" 카드에 ABC/TOP 한정 3줄 추가:
  - **목표까지**: 현재가→C목표 거리(%, +초록)
  - **무효화까지**: 현재가→무효화가 거리(%, −빨강)
  - **손익비(R:R)**: `|목표%| / |무효화%|`를 `X.XX : 1`로.
  - 현재가 0/비유한 또는 값 누락 시 전체 생략(방어).

### 검증

- 프론트 `typecheck`/`build` 통과. **Chrome smoke 0에러**. ABC 신호 상세에서 손익비·목표까지·
  무효화까지 렌더 DOM 확인. 백엔드/계약 무변경.
